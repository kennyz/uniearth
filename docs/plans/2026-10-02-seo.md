# UniEarth SEO Implementation Plan

**Goal:** Improve discovery and sharing of the existing homepage and interactive map without changing their layout or map behavior.

**Architecture:** Keep the static HTML site. A shared `seo.js` synchronizes localized titles, descriptions and social metadata. A Python build script writes domain-dependent canonical URLs, JSON-LD, robots.txt and sitemap.xml from one configuration. The offline map inherits the online map canonical when regenerated.

**Tech Stack:** HTML, JavaScript, Python standard library; Pillow for the share image; existing jsdom checks for regressions.

## Audit and scope

- Homepage has one H1 and useful static feature content, but generic metadata and no sharing tags.
- Map lacks a description, H1 and static explanation; its content depends on JavaScript.
- No canonical URLs, robots.txt, sitemap or structured data exist.
- No deployment URL is recorded in the checkout or GitHub repository homepage. Ask for the production URL; never emit an invented canonical or sitemap URL.
- English is the current default HTML language. Chinese is an interactive translation; this change does not add independently indexable language routes or hreflang assertions.
- Live index coverage, Search Console errors and field Core Web Vitals need a deployed URL and account access; local verification cannot establish ranking or field performance.

## Implementation

1. Add page-specific English/Chinese metadata and synchronize title, description, Open Graph and Twitter tags when language changes.
2. Add a concise static map summary with H1 and a usable no-script message. Keep the map viewport intact; make the summary accessible without displaying duplicate marketing sections.
3. Generate a 1200 × 630 PNG share image from the existing geographic dataset and visual palette.
4. Add `seo-config.json` and `build_seo.py`. Generate WebSite/WebPage/WebApplication JSON-LD, crawl rules and a two-page sitemap once the real URL is configured. Normalize query variations and the offline file to the main online map; do not block resources crawlers need to render.
5. Regenerate `world-map.html` through `make_single.py` and document the SEO build and deployment checks in README.

## Validation

- Parse metadata, JSON-LD and sitemap; verify absolute URLs and canonical consistency, offline deduplication and local resource existence.
- Run language tests and map smoke checks for both map entry points. Exercise homepage language switching, including blocked storage.
- Serve locally and verify page/resource HTTP responses and share image appearance. Review the patch and confirm no unrelated edits.

Reference: Google Search Central documentation on JavaScript SEO, canonical URLs and sitemaps. No keyword volume, ranking gains or live performance claims are assumed.
